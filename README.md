FinGuard

A banking transaction and fraud detection system built with Java and Spring Boot.

FinGuard lets you create accounts, transfer money between them, and checks every transaction against fraud rules. Results are shown on a simple dashboard.

Dashboard

Features
Create accounts and transfer money
Transaction history
Fraud detection with four rules: high amount, velocity, unusual hour and balance drain
Error handling for invalid transfers
Simple web dashboard
Tech Stack
Java
Spring Boot
Maven
PostgreSQL
How to Run
Clone the repository:
bash
   git clone https://github.com/Robin6502/fin-guard-banking-system.git
   cd fin-guard-banking-system
Create a PostgreSQL database called finguard.
Set your database login:
bash
   export DB_USER=postgres
   export DB_PASSWORD=your_password_here
Start the app:
bash
   mvn spring-boot:run
Open http://localhost:8080 in your browser.
